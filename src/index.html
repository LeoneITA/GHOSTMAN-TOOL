Plugin installati

LOCAL

File e cartelle community sul PC

Importa file, cartelle o archivi ZIP/RAR. Le cartelle mostrate qui restano nella libreria; quelle con manifest.json possono essere installate come plugin Python. I siti con index.html si possono provare anche dal telefono.

I plugin Python partono solo quando premi Esegui e operano con gli stessi permessi dell'app. Installa soltanto codice di cui ti fidi.

I plugin Python scaricati devono essere estratti prima; poi premi “Installa plugin da cartella” e seleziona la cartella contenente manifest.json. Il codice può accedere ai file e alle risorse del tuo account Windows: installa soltanto plugin verificati e fidati.

Per autorizzare un plugin sul telefono, abilita "Consenti remoto" solo dopo averne verificato il codice.

PRIVATE TAILNET

Accesso mobile

Avvia i plugin approvati dal telefono, anche su rete mobile, tramite la tua rete privata Tailscale.

Accesso remoto spento

OFFLINE

Installa Tailscale su questo PC e sul telefono e accedi allo stesso tailnet. Non vengono aperte porte del router.

Scansiona entro 60 secondi

Il link vale per una sola associazione; la sessione viene legata all'account Tailscale e revocata quando disattivi il servizio o chiudi GHOSTMAN.

Prima di iniziare

Tailscale deve essere installato e connesso su PC e telefono allo stesso tailnet. Abilita MagicDNS, certificati HTTPS e Serve nelle impostazioni Tailscale. Il link QR scade dopo 60 secondi. Il telefono vede solo plugin Python che approvi nel Plugin manager; le esecuzioni vengono registrate senza salvare gli input.

I plugin eseguono codice con i permessi del tuo account Windows. Abilita il remoto solo per script fidati.
